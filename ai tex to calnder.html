Quick Start Tutorial
  1. Set Title: Start with a ::: config block to set your App Title.
  2. Define Month: Use ::: calendar and ++ Month Year ++ to start a month.
  3. Add Events: List dates like 01 * New Year. Use symbols for colors!
  4. Add Details: Use ::: details and >> Date to add stories, images, and rituals.
  5. Customize: Add Panchang and Seasons to make it professional.
1. App Configuration
::: config @ Title : My Calendar 2026 @ Logo : ![Logo](https://example.com/logo.png) @ Live Sync GitHub trigger in every : 24 hours :::

- Title: Appears in the top header.
- Logo: URL or uploaded image path.
- Live Sync: Auto-update interval (minutes/hours/days).

2. Calendar Grid Events
::: calendar ++ January 2026 ++ 01 * New Year's Day [ନୂତନ ବର୍ଷ] 14 ! Makar Sankranti 23 ! Saraswati Puja / Netaji Jayanti 26 ^ Republic Day 05 > Office Meeting :::
! Festival (Red)
* Holiday (Blue)
^ Auspicious (Green)
> Event (Gray)

Bilingual Support: Use [Local Text] brackets to show regional text below the English name.

Multiple Events: Use / to separate multiple events on the same line (e.g. Event 1 / Event 2).

2a. Recurring Events
::: recurring 01-01 * New Year 26-01 ^ Republic Day 15-08 ! Independence Day :::

Events that repeat every year on the same Gregorian date. Format: DD-MM.

3. Tithi Overrides (Hybrid Mode)

Manually force a Tithi for specific dates (overrides calculation).

::: tithi 14-01-2026 : Purnima 25-01-2026 : 10 29-01 : Amavasya # Applies every year :::
4. Detailed Day View

Add rich content and banners for any date.

::: details >> 14-01-2026 ![Banner](https://image.url/banner.jpg) ## tag : Major Festival, Public Holiday # Significance **Makar Sankranti** is a major harvest festival. It marks the sun's transit into *Makara* (Capricorn). # Rituals - Holy dip in river - Flying kites :::

Syntax Features:

  • >> DD-MM-YYYY : Target a specific date.
  • ![Banner](url) : Add a top banner image.
  • # Header : Section titles.
  • **Bold**, *Italic* : Text styling.
5. Monthly Panchang
::: panchang @ Tithi : Shukla Paksha @ Nakshatra : Rohini @ Yoga : Indra @ Karana : Bava @ Sunrise : 06:20 AM :::

Data appears in the "Panchang" card.
Note: Tithi/Nakshatra are also auto-calculated if omitted!

6. Seasons (Ritu)
::: seasons @ Spring : Flowers blooming everywhere. @ Summer : Scorching sun, mango season. :::

Customize text for: Spring (Vasant), Summer (Grishma), Monsoon (Varsha), Autumn (Sharad), Pre-Winter (Hemant), Winter (Shishir).

7. MONTH PARTITION
-----------------------------------

Use exactly 35 hyphens on a single line to visually partition months in the editor. This helps keep your configuration file clean and readable without affecting the calendar data.
